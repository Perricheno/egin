# Sources and provenance

All provider data is obtained by the backend. No fabricated measurements are included in seed data. Provider caches record payload, fetch time and expiry. The UI distinguishes fresh/cached/stale/unavailable.

| Data | Source / license | Processing and limitations |
|---|---|---|
| Kazakhstan ADM0/1/2 | [HDX COD-AB KAZ](https://data.humdata.org/dataset/cod-ab-kaz), UNHCR 2023, CC BY-IGO | Original shapefile archive, SHA256 recorded in `data/boundaries-source.json`. Names retained in available languages, source EPSG:3857 coordinates transformed, geometries repaired and normalized to EPSG:4326 MultiPolygon. Largest intersection assigns region/district. These are 2023 source boundaries, not a claim of complete 2026 administrative currency. |
| Base map | [OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL | Standard raster tile service with visible attribution; no bulk tile downloading. Local previews need internet for the base map. |
| Geocoding | [Nominatim public service](https://operations.osmfoundation.org/policies/nominatim/), OSM attribution | Explicit submit only; backend cache 7 days; <=1 request/second across the process; Kazakhstan filter. Saved fields work when search fails. |
| Forecast | [Open-Meteo](https://open-meteo.com/en/docs), data CC BY 4.0 | Hosted free non-commercial API. 7-day daily min/max temperature, precipitation and probability, wind, weather code, ET0, radiation; current humidity and hourly shallow soil moisture/temperature retained. Cache 30 minutes, stale fallback. Free-service terms must be reevaluated before commercial deployment. |
| Soil primary | [ISRIC SoilGrids v2](https://rest.isric.org/), data CC BY 4.0 | 250 m global model; phh2o, SOC, clay/silt/sand, bulk density, CEC. 0–5, 5–15, 15–30 cm means weighted by thickness. Provider conversion factor applied; texture fractions converted from g/kg to percent only when not already percent. Raw depth means retained. The primary request uses means only to limit provider latency; it does not supply uncertainty quantiles. Cache 30 days; <=5 upstream requests/minute; point key rounded to 0.001°. |
| Soil fallback | [OpenLandMap STAC](https://stac.openlandmap.org/), selected collections CC BY 4.0 | OpenLandMap-soildb COGs for 2020–2022, 0–30 cm, 120 m assets for pH, SOC and clay, with P16/P84 where reads succeed. Uses bounded pixel windows over HTTP ranges. A subprocess deadline terminates stalled GDAL. Does not download global rasters. Exact collection/item metadata is included under `data/`. Missing properties remain empty. |
| Historical climate | [NASA POWER](https://power.larc.nasa.gov/docs/services/api/), open NASA data with attribution | Monthly AG community T2M, PRECTOTCORR, ALLSKY_SFC_SW_DWN, WS2M. Three complete years prior to current year; May–August mean temperature and average seasonal rainfall. Monthly rain rate (mm/day) multiplied by days/month. This is a short historical summary, not a 30-year climate normal or realtime forecast. Cache 30 days with year-specific key. |
| News | ElDala RSS / AgroInfo RSS probes | Feed requests are optional with timeout and source-link attribution. AgroInfo successfully imported 20 linked articles in the live verification; ElDala was unavailable. Seed contains explicitly labeled educational DEMO content without a fake publication date. `python -m app.news` retries ingestion. |
| ML | EGIN DEMO_SYNTHETIC generator, CC0-1.0 generated rows | 3,900 synthetic rows, six crops. Exact provenance, assumptions, features and validation metrics in model metadata. No Kazakhstan field-label dataset is claimed. See ML.md. |

Soil is a spatial model estimate, not a laboratory analysis. Thickness-averaged SoilGrids quantiles are not confidence intervals for an entire field. OpenLandMap P16/P84 ranges must not be mislabeled as SoilGrids Q05/Q95. Feature importance is global model importance, not a causal agronomic explanation.

Actual source archives are cached under ignored `data/downloads/`; public STAC metadata is versioned. No personal field coordinates are sent to unrelated services: weather, soil and climate receive only the selected centroid; geocoding receives explicit searches. The structured assistant uses local tools and does not transmit farm content to a remote LLM.

Live verification: ISRIC returned real seven-property means for the demo northern field, Open-Meteo returned a seven-day forecast, and NASA POWER returned the 2023–2025 monthly history. OpenLandMap's bounded COG request hit its deadline on this machine; no successful raster fallback values are claimed. Cached real SoilGrids data remains available if that upstream service later fails.
